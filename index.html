01 / SERVER · C++

멀티플레이 서버

하나의 상주 데디케이티드 서버가 로비와 매치 맵을 ServerTravel로 오가는 통합 구조로 설계·구현했습니다. 로비 슬롯과 방장은 복제하고, 닉네임·AI 슬롯·방장 주소는 GameInstance에 저장해 매치를 왕복해도 유지됩니다. 방장 권한은 서버 RPC 진입점에서 검사하고, 매치 종료 시 전원 투표로 로비에 복귀합니다. 캠페인은 로컬 전용 서버 프로세스를 띄워 처리합니다.

DEDICATED SERVER · SERVERTRAVEL · REPLICATION · RPC
02 / MAP GIMMICK · C++ & BP

점프패드 · 비대칭 탄도

상승·하강 중력을 달리한 비대칭 포물선 궤적을 계산하는 점프패드를 만들었습니다. 상승 구간은 닫힌 해로, 하강 구간은 이분탐색으로 풀고, 계산은 Blueprint 커스텀 노드, 상태 전환은 Actor Component로 책임을 나눴습니다. AI 봇도 NavMesh 도달 가능성을 확인하며 사용합니다.

CUSTOM NODE · ACTOR COMPONENT · DATA ASSET
03 / AI · BLUEPRINT

추격 AI 컨트롤러 · EQS

AI 컨트롤러가 지각, 기억, 무기별 교전 거리 계산을 담당해 Blackboard로 넘기고, Behavior Tree는 판단만 하도록 역할을 나눴습니다. 시야를 잃으면 마지막 위치를 NavMesh에 투영해 추적하고, 전투·후퇴 위치를 고르는 EQS 쿼리와 컨텍스트를 직접 설계했습니다. (BT 내부와 무기 가중치 테이블은 팀원 작업)

AI PERCEPTION · BLACKBOARD · EQS
04 / GAMEFLOW · INVENTORY

화면 흐름 · 인벤토리

메인메뉴, 로비, 맵·난이도 선택, 매치, 결과로 이어지는 화면 흐름과 무기 스왑 로직(습득, 이전·다음 교체, 재충전), 인벤토리 인터페이스, HUD 연동 일부를 Blueprint로 구현했습니다.

WIDGET · BPI_INVENTORY · OnSwapItem
TROUBLESHOOTING

실서버 테스트에서 찾고 고친 문제

  • 결과창에서 "로비로"를 누르면 클라이언트 전원이 튕김 — 매치가 별도 프로세스라 매치 종료와 함께 서버가 죽었습니다. 매치를 상주 서버의 ServerTravel로 전환해 서버가 살아 있는 채로 로비로 복귀하도록 재설계했습니다.
  • 매치를 왕복하면 AI 슬롯·방장·닉네임이 초기화 — ServerTravel로 GameState가 새로 만들어지는 것이 원인이었습니다. 값을 GameInstance에 저장해 두고 로비가 구성될 때 복원했습니다.
  • 비대칭 궤적이 공식 하나로 풀리지 않음 — 닫힌 해가 나오는 구간과 아닌 구간을 수학적으로 먼저 나누고, 하강 구간만 이분탐색으로 수치 해를 구했습니다.

학교 서버 PC에 상주 서버를 띄우고 다른 PC에서 IP로 접속하는 조건으로 반복 테스트했습니다. 리슨 서버에서는 보이지 않던 버그를 이 조건에서 찾아 수정했고, 커밋을 시스템 단위로 나눠 회귀 원인을 좁혔습니다.
